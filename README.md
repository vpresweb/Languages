# Languages

Английский и португальский в одном веб-приложении: словари, запоминание слов и курсы по методу Фейнмана.

Онлайн: https://vpresweb.github.io/Languages/

## Разделы

Язык переключается вверху (English / Português), разделы и подразделы — вкладками.

- **Словарь** — поиск в обе стороны (EN ↔ RU, PT ↔ RU): 50 000 английских и 46 680 португальских статей,
  формы английских глаголов и спряжение португальских, поиск по формам (`went` → `go`, `fazes` → `fazer`),
  подсказки при опечатке, произношение. У каждой статьи — кнопка **«Учить»**: слово встаёт первым в очередь
  новых слов раздела «Слова». **Тест глаголов** — формы английских глаголов или спряжение португальских.
- **Слова** — запоминание слов:
  - *Сегодня* — повторения и новые слова на сегодня, серия дней, прогноз на неделю, занятие:
    знакомство с новыми словами быстрым потоком, затем карточки «вспомни → проверь → оцени»
    с интервальным повторением (SM-2, как в Anki);
  - *Поток* — быстрый показ слов; **аудиорежим** читает слово и русский перевод вслух и продолжает
    звучать в свёрнутой вкладке;
  - *25-й кадр* — экспериментальный режим со вспышками слов; эффект не доказан, на прогресс не влияет;
  - *Настройки* — новых слов в день, направление карточек, резервная копия прогресса.
- **Курсы** — 12-недельные курсы по методу Фейнмана: британский английский A1, A2, B1, B2 и европейский
  португальский A1, A2. Курс открывается внутри приложения со своего сайта, поэтому все изменения в
  репозиториях курсов сразу видны и здесь.

Адреса разделов: `#/en/dict`, `#/pt/dict/quiz`, `#/en/words`, `#/en/words/stream`, `#/pt/courses/a2` и т. д.

## Прогресс

Прогресс хранится в браузере (localStorage). Приложение работает на том же сайте `vpresweb.github.io`,
что и прежние программы, и использует те же ключи, поэтому подхватывает уже накопленный прогресс
запоминания слов (Word_Memory), настройки тестов словарей и прогресс курсов.

## Из чего собрано

Приложение объединяет репозитории:
[Dictionary_English](https://github.com/vpresweb/Dictionary_English),
[Dicionario_Portugues](https://github.com/vpresweb/Dicionario_Portugues),
[Word_Memory](https://github.com/vpresweb/Word_Memory) и курсы
[English_A1](https://github.com/vpresweb/English_A1), [A2](https://github.com/vpresweb/English_A2),
[B1](https://github.com/vpresweb/English_B1), [B2](https://github.com/vpresweb/English_B2),
[Portuguese-by-Feinman](https://github.com/vpresweb/Portuguese-by-Feinman),
[Portuguese-by-Feinman-A2](https://github.com/vpresweb/Portuguese-by-Feinman-A2).
Прежние сайты продолжают работать.

## Структура

```
index.html                  оболочка: язык, разделы
css/style.css               стили (светлая и тёмная тема)
js/app.js                   адреса и переключение разделов
js/speech.js                произношение (Web Speech API), общее для всех разделов
js/dictionary-view.js       раздел «Словарь» и кнопка «Учить»
js/courses.js               раздел «Курсы»
js/words/                   раздел «Слова» (бывший Word_Memory): view.js, srs.js, session.js, learn.js,
                            stream.js, flash.js, storage.js, data.js
dict/en/, dict/pt/          языковые части словарей: поиск, формы/спряжение, вывод статей, тест
data/dict-*.json            полные словари
data/words-*.json           основные слова для раздела «Слова» (по частоте)
scripts/build-data.mjs      сборка data/ из репозиториев словарей
tests/                      тесты (node --test)
```

## Разработка

Сборка не нужна — это статические файлы. Локально нужен любой веб-сервер:

```
python -m http.server 8000
```

Тесты: `npm test` (Node.js 20+). Обновить данные после изменения словарей (репозитории словарей должны
лежать рядом): `npm run build-data`.
